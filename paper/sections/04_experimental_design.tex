\section{Experimental Design}

\subsection{Goals and primary data-generating model}

The experiments evaluate finite-reference power rather than establish validity, which follows from Theorem~1. The primary frozen simulation uses
\[
  K\in\{24,32\},\qquad m=2,\qquad n=K-2,
\]
with clean reference values \(Y_i\sim\mathrm{Uniform}(0,1)\). The original two contaminated references are fixed at value \(2\). Under the null,
\[
  X_t\sim\mathrm{Uniform}(0,1),
\]
and under alternatives
\[
  X_t\sim\mathrm{Beta}(\gamma,1),
  \qquad \gamma\in\{2,4,8\}.
\]
The maximum horizon is \(T=200\), with intermediate reporting at \(T\in\{40,100,200\}\), and the nominal anytime level is \(\alpha=0.05\). All methods use identical simulated paths within each replication.

\subsection{Static-coupling method and oracle}

For each path, every candidate set \(C\subseteq\{1,\ldots,K\}\) with \(|C|=2\) is evaluated. Candidate ranks are given by \eqref{eq:candidate-rank}, the frozen predictive-rank portfolio is applied, and the robust statistic is \(\underline E_t\). A detection occurs when
\[
  \underline E_t\ge20.
\]

The oracle knows \(C^\star\) and applies the same betting portfolio directly to the true clean rank sequence. Its threshold is also 20. It quantifies the cost of unknown contamination identities.

\subsection{Confidence-band baselines}

The comparison baselines discard contamination identities and represent reference uncertainty through simultaneous CDF bounds. Let
\[
  q(x)=\#\{\text{all }K\text{ observed references}\le x\}.
\]
Because exactly \(m\) observations are arbitrary replacements,
\[
  \max\{0,q(x)-m\}
  \le q_{\mathrm{clean}}(x)
  \le \min\{n,q(x)\}.
\]
For DKW radius
\[
  \epsilon_n(\delta)
  =
  \sqrt{\frac{\log(2/\delta)}{2n}},
\]
the exact-count lower bound is
\begin{equation}
  L_\delta(x)
  =
  \max\left\{
    0,
    \frac{\max(0,q(x)-m)}{n}
    -
    \epsilon_n(\delta)
  \right\}.
  \label{eq:exact-count-band}
\end{equation}

A symmetric contaminated-reference radius follows from
\[
  \widetilde F_K
  =
  \frac nK\widehat F_{\mathrm{clean}}
  +
  \frac mK\widehat F_{\mathrm{bad}},
\]
giving
\begin{equation}
  \epsilon_{\mathrm{sym}}(\delta)
  =
  \frac nK\epsilon_n(\delta)
  +
  \frac mK.
  \label{eq:sym-band}
\end{equation}
This radius is inserted into a one-sided CCTM-style betting geometry. These contaminated-reference constructions are ours for comparison; they are not algorithms claimed by Shaer et al.~\cite{ShaerEtAl2026}.

\subsection{Frozen baseline-strength audit}

The final audit sweeps
\[
\begin{aligned}
\delta\in\{&
0.005,0.010,0.015,0.020,0.025,\\
&0.030,0.035,0.040,0.045\}.
\end{aligned}
\]
For target marginal level \(\alpha=0.05\), each confidence-band configuration uses
\[
  a(\delta)
  =
  \frac{\alpha-\delta}{1-\delta}
\]
and threshold \(1/a(\delta)\), corresponding to the conservative marginal budget
\[
  a(1-\delta)+\delta\le\alpha.
\]

Three baseline families are evaluated:
\begin{enumerate}[leftmargin=*]
  \item a fixed mixture over \(\eta\in\{0.05,0.10,0.20,0.40,0.60,0.80,0.95\}\) using \(h_t=2(L_\delta(X_t)-1/2)\), with a \(5\%\) constant-one hedge;
  \item one-dimensional online Newton step betting with predictable \(\eta_t\in[0,0.99]\) on the same exact-count lower-band signal; and
  \item a one-sided CCTM-style ONS comparator using \eqref{eq:sym-band} with \(D\in\{0.50,0.90,0.99\}\).
\end{enumerate}

For the original publication-scale table we report the strongest configuration selected \emph{ex post} from this frozen grid. This envelope is a descriptive adversarial benchmark rather than one precommitted level-\(\alpha\) test. At the primary \(K=32,\gamma=4,T=200\) point, the selected member is the fixed band mixture with \(\delta=0.045\).

\subsection{Development freeze and publication-scale validation}

The development audit used 200 Monte Carlo paths per condition with seed \(20260918\). Before inspecting the final development results, the primary stress point was fixed at
\[
  K=32,\qquad \gamma=4,\qquad T=200,
\]
and a strong empirical pass required
\[
  \widehat P_{\mathrm{static}}
  -
  \widehat P_{\mathrm{strongest\ frozen-grid\ baseline}}
  \ge0.15.
\]
No bettor, threshold, baseline grid, or detector parameter was changed after this criterion was evaluated.

The publication-scale validation increased only Monte Carlo precision. It used 5,000 independent replications per condition, deterministic publication seed \(20260922\), and the identical frozen method and baseline grids. Crossing probabilities are reported with Wilson 95\% intervals. Median stopping times among detected paths are reported with percentile-bootstrap 95\% intervals based on 2,000 bootstrap replications. Null Monte Carlo is used only as an implementation sanity check.

\subsection{Pre-specified contamination-geometry stress test}

After the method freeze and the publication-scale run, a separate V1b protocol was specified and committed to the project history before any V1b outcome was viewed. It keeps \(K=32\), \(m=2\), \(\alpha=0.05\), the same horizons, alternatives, bettor portfolio, thresholds, and baseline grid. Each V1b condition uses 5,000 replications and reuses the Publication V1 clean-reference/future-stream path seeds so that geometry comparisons are paired.

The four frozen contamination geometries are:
\begin{enumerate}[leftmargin=*]
  \item \texttt{high\_outside}: \((2.0,2.0)\), the Publication V1 control;
  \item \texttt{upper\_inside}: \((0.85,0.95)\);
  \item \texttt{mixed\_inside}: \((0.10,0.90)\);
  \item \texttt{random\_static\_inside}: two iid \(\mathrm{Beta}(1/2,1/2)\) values sampled independently of the clean reference and future stream once per replication.
\end{enumerate}

Because the in-support contaminants occupy random sorted positions, the oracle true-candidate index is recomputed for every replication. The V1b comparator is fixed before V1b geometry outcomes as the band mixture with \(\delta=0.045\); the full frozen grid remains a secondary descriptive envelope. This configuration had been identified in the earlier Publication V1 analysis, and V1b reuses the Publication V1 control paths; accordingly, V1b bootstrap intervals are interpreted as Monte Carlo uncertainty conditional on this designated comparator, not as selection-adjusted confirmatory inference. In addition to crossing probabilities, V1b reports the empirical detection CDF and the horizon-truncated stopping metric
\[
  \tau_T^\dagger
  =
  \begin{cases}
  \tau,&\tau\le T,\\
  T+1,&\text{otherwise},
  \end{cases}
\]
so non-detections are included in the delay-like summary.

\subsection{Semi-synthetic RTL-SDR validation}

The engineering validation uses real unsigned 8-bit IQ from an RTL-SDR Blog V4 receiver attached to an Orange Pi sensor node, with controlled post-ADC tone injection. Both V1 and V2 keep \(K=32\), \(m=2\), \(T=200\), log mean block power as the scalar score, 16,384-sample blocks, stride 32,768, manual gain 28 dB, and the fixed \texttt{band\_mix}, \(\delta=0.045\), comparator. Two physical reference-block identities receive a \(+6\) dB post-ADC tone.

SDR V1 uses 20 fresh 10 s captures and the injected-SNR grid \(\{-12,-6,-3,0\}\) dB. Because the proposed method is already saturated at \(-12\) dB, a separate post-V1 protocol was specified and frozen before V2 detector outcomes and executed on 30 fresh captures using \(\{-24,-21,-18,-15,-12\}\) dB. All V1 and V2 captures passed their pre-outcome QC gates.

The score streams exhibit non-negligible serial dependence. Accordingly, the SDR experiments are reported as external engineering sensitivity characterizations only. They are not used to claim hardware false-alarm control, iid validity, or analog front-end response to an over-the-air signal; injection occurs after ADC.
