\abstract{%
Sequential distribution-shift detection often relies on a finite reference bank that may already contain persistent interferers or outliers. We study a fixed reference containing an unknown set of static, exogenous replacements whose identities remain unchanged during monitoring. For each candidate set of contaminated sorted positions, we reconstruct a candidate clean-reference rank sequence and apply a predictive-rank betting rule. The true candidate exactly recovers the clean rank process, so the pointwise lower envelope of candidate wealths is pathwise dominated by a valid clean predictive-rank martingale, yielding finite-sample anytime threshold-crossing control. A corollary permits only an upper bound on the contamination count, while the induced contiguous-partition structure gives an exact \(O(Km^2)\) dynamic program for a fixed categorical bettor. In 5,000 post-freeze simulations with \(K=32\), \(m=2\), \(T=200\), and a \(\mathrm{Beta}(4,1)\) shift, crossing probabilities were \(0.9144\) for static coupling, \(0.1152\) for the designated confidence-band comparator, and \(0.9810\) for the oracle. A pre-specified geometry stress test retained static crossing probabilities of \(0.8894\)--\(0.9468\) across three non-control geometries. Semi-synthetic RTL-SDR experiments with real receiver/background IQ and controlled post-ADC injection reproduced the qualitative sensitivity advantage. These hardware experiments are engineering sensitivity checks, not type-I validation.
}

\resumen{%
La detecci\'on secuencial de cambios de distribuci\'on suele apoyarse en un banco finito de referencia que puede contener interferencias u observaciones at\'ipicas persistentes. Estudiamos una referencia fija con reemplazos est\'aticos y ex\'ogenos desconocidos cuyas identidades permanecen invariantes durante el monitoreo. Para cada conjunto candidato de posiciones contaminadas ordenadas, reconstruimos una secuencia de rangos respecto de la referencia limpia y aplicamos una regla de apuestas predictiva. El candidato verdadero recupera exactamente el proceso de rangos limpio; por ello, la envolvente inferior de las riquezas candidatas queda dominada camino a camino por una martingala v\'alida y proporciona control finito de cruces de umbral v\'alido en cualquier momento. Un corolario permite usar solo una cota superior para el n\'umero de contaminantes, y la estructura de particiones contiguas produce un programa din\'amico exacto \(O(Km^2)\) para un apostador categ\'orico fijo. En 5.000 simulaciones poscongelamiento con \(K=32\), \(m=2\), \(T=200\) y un cambio \(\mathrm{Beta}(4,1)\), las probabilidades de cruce fueron \(0.9144\) para el acoplamiento est\'atico, \(0.1152\) para el comparador designado y \(0.9810\) para el or\'aculo. Una prueba de estr\'es geom\'etrica pre-especificada mantuvo probabilidades de cruce de \(0.8894\)--\(0.9468\) en tres geometr\'ias no control. Experimentos semi-sint\'eticos con RTL-SDR, IQ real del receptor/fondo e inyecci\'on pos-ADC reprodujeron cualitativamente la ventaja de sensibilidad. Estos experimentos eval\'uan sensibilidad de ingenier\'ia, no control de error tipo I.
}
